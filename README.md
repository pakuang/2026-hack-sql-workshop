# 🕵️ SQL Mystery Workshop  
## Opening the Database in DataGrip

Welcome! Follow the steps below to open the database file in DataGrip.

---

## 📁 Step 1: Download the Files

Make sure you have:

- `db.sqlite`

Save them somewhere easy to find (Desktop or Downloads is fine).

---

## 🛠 Step 2: Open DataGrip

Launch **DataGrip**.

---

## ➕ Step 3: Add the Database

1. Click **File** on the top bar and click **Open**.

---

## 📦 Step 4: Download Driver (If Prompted)

If DataGrip says:

> "Driver files are missing"

Click:

**Download**

This only happens the first time you connect to SQLite.

---

## ▶ Step 5: Run Queries

1. Right-click the database
2. Select **New → Query Console**
3. Paste your SQL query
4. Press:

- **Mac:** `Cmd + Enter`
- **Windows:** `Ctrl + Enter`

---

## 💾 Editing Data (Important)

If you manually edit rows:

- Click the **✔ Commit** button  
**OR**
- Press `Cmd + Enter` (Mac) / `Ctrl + Enter` (Windows)

If you do **not** commit, your changes will not be saved.

---

## 🔄 Resetting the Database

If something breaks:

1. Close DataGrip
2. Delete your modified `.sqlite` file
3. Re-download the original file
4. Reconnect
